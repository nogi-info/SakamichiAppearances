# SakamichiAppearances

坂道グループ（乃木坂46・櫻坂46・日向坂46）メンバーのYouTube出演動画をまとめるデータベース「坂道出演情報」の公開用リポジトリです。

GitHub Pages で公開します。データは公開済みの動画メタデータのみを含み、認証情報は含みません。

## 現在の状態（試作）

- 対象は乃木坂46のみ（メンバー99名・現役33名）
- `index.html`：動画一覧（区分・メンバー・期・キーワードで絞り込み、再生数順ソート）とメンバー一覧
- `data/members.json`：メンバー台帳。事実（加入日・卒業日・加入期ラベル）だけを保持し、現役/OGは卒業日と現在日時の比較で表示時に導出する。加入期は label / group（同一視用）/ sort（並び順）の3値で持ち、「新4期」は group=4 として4期と同一視できる
- `data/videos.json`：掲載対象の動画のみ（公式チャンネルの動画＋正規判定チャンネルの出演動画）。収集した候補の総数も meta に記録

## データの更新

収集台帳（YouTube出演収集の試行）とメンバー台帳から生成スクリプトで `data/` を再生成し、コミット・push すると GitHub Pages に反映されます。
